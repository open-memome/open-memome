# 0001: GitHub as the first public contribution ledger

Date: 2026-08-22

Status: accepted

## Decision

Use GitHub issues and pull requests for candidate submission, evidence review, disputes, contributor identity, moderation, and version history during the public alpha.

## Why

The project needs a working, inspectable contribution loop before it needs a custom social platform. GitHub already supplies durable identity, discussion, review, permissions, automation, and history.

## Consequences

Contributors need a GitHub account. The website opens structured issue forms rather than storing submissions itself. A custom review service may replace or complement this system after contribution volume and reviewer behaviour justify it.
